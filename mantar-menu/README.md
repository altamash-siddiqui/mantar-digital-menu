# Mantar Restaurant — QR Digital Menu

A mobile-first, static QR menu experience for Mantar Restaurant, Lucknow.

## Flow
QR scan → welcome/cover → subtle animation → OPEN MENU → interactive menu.

## Included
- Mantar logo
- 10-page Mantar Menu PDF source
- Interactive menu categories
- Search
- Prices displayed as **MRP ₹...**
- Call / Directions / Instagram
- Original Menu link
- No admin panel, no login, no cart, no ordering, no payments
- No individual food images

## Current note
